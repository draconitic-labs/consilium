    Set up Consilium

    Use a local endpoint, an installed provider CLI, or a direct API. Consilium itself has no paid tier or required account.

    1 · Fully local

    Start an OpenAI-compatible server, then create the plain-text configuration file at the path shown below. For example:

    OPENAI_COMPAT_BASE_URL=http://127.0.0.1:11434/v1
OPENAI_COMPAT_MODEL=qwen3:8b

    Replace the model with the exact ID exposed by your server. Create the configuration directory first if it does not exist.

    2 · Provider CLI

    Install Grok, Claude Code, Codex, or Gemini/Antigravity. Use the connector's visible Sign in action to launch the provider-owned flow, then restart Consilium so availability is refreshed.

    3 · Direct API

    Add the provider key and required model ID to the ignored per-user .env. Direct-provider charges and terms belong to that provider; they never unlock a Consilium feature.

    Installed CLI sign-in

    Launch an installed provider's own account flow here. Complete it in the terminal/browser it opens, then restart Consilium.

    Display

    When off, a still image is shown and WebGL is not used. If the field freezes twice in a row while starting, Consilium turns this off. The system reduced-motion setting is always honored.
